# 东北大学教务焕新

这是一个 Manifest V3 Chrome 插件（当前版本 0.3.101）和 Android 应用（当前版本 0.1.76），为东北大学本科教务管理系统提供一个独立的新标签页/移动端查询台，不再向原系统注入侧边栏。

查询页保留 `AndroidApi` 原生桥兼容分支，浏览器插件和 Android WebView 共用同一套界面与数据映射逻辑。Android 工程和插件源码均位于本仓库；可安装文件请从 GitHub Releases 下载。

## 当前功能

- 点击浏览器工具栏中的插件图标，会打开 `dashboard.html` 新标签页。
- 成绩：调用“培养 → 成绩综合查询”的实际 `cxwdcj.do` 完整成绩接口，展示课程号、学分、总成绩、绩点、课程类别、课程性质、通识选修类别、考试类型、修读状态、通过状态和获得学期。
- 成绩详情与平均绩点：点击成绩数字读取原系统 `api/wdcj/details.do` 的平时、期中、期末等分项成绩；平均绩点按全部已查询学期的成绩明细进行“绩点 × 学分”的加权累计，不受当前成绩表下拉框影响，并按学号规则标注 25 级及以后排除通识选修和二级分制课程（包括“合格/不合格”等二级成绩表现）、24 级及以前纳入全部课程；同时保留原系统累计总绩点作对照，并显示实际排除的课程。
- 新成绩提醒：进入成绩页后会主动读取最新数据，并按“学号 × 查询学期”保存不可逆成绩指纹；只有该学期相对既有基线新增的成绩才弹窗提醒。首次查看没有可靠缓存的学期只建立基线，切换历史学期不会把整学期成绩误报为新增。
- 培养方案与成绩联动：培养方案页会汇总所有已查询学期中已通过的成绩，按课程号优先、课程名兜底匹配培养方案课程；对于原系统只返回“通识选修课”学分要求、没有具体课程行的课组，会按三个通识选修类别的字段自动归类并把已选课程补显示在对应课组中，同时计入已获得学分。每个课组和每门课程显示已获得学分、剩余所需学分、必修/选修完成情况和匹配到的成绩；进度统计按各课组、必修/选修和方案总学分要求分别封顶，超修课程不会把已获得学分算到要求以上，也不会产生负数剩余；通识选修仍按 25 级及以后 GPA 规则排除，只是不影响培养方案学分统计。补显示的通识选修仅存在于当前用户页面内；PDF 只按白名单导出方案结构、课程要求，以及课程完成状态/成绩/学期，不导出姓名、学号、账号或原始接口对象。
- 培养方案视觉与筛选：培养方案页先展示当前方案、毕业进度、已获得/剩余/完成课程和学分构成，再以紧凑树展示 L1-L4 课组；桌面端页面使用更宽的有效内容区，支持单按钮“展开全部/收起全部”、逐级展开、搜索、必修/选修、学期和“只看待完成”。导出时由专用数据模型生成 A4 横向多页 PDF：固定 8 列、重复表头、按课程行分页，不受页面折叠状态影响，也不带浏览器页眉页脚或个人信息。如果刷新后出现“智能车辆工程”等明显不属于本人专业的方案，应先等待原教务系统培养方案页面完全加载，再点击“刷新方案”。
- 考试信息：调用“运行 → 考务管理”的考试接口，自动解析考试描述中的日期、星期、起止时间、场次、考场、座位号和教师，并按考试时间排序，以卡片和倒计时状态展示。
- 个人课表：调用“运行 → 课表查询 → 我的课表”的课程列表和课表网格接口；网格存在时优先使用网格的星期、节次、周次、教师、校区和教室，网格未返回或只返回部分安排时会从课程原始记录补全。校区作为独立的已映射字段随个人缓存保存，详情页组合显示校区与教室，其他课表视图只显示教室/线上地点。同一门课程的多条排课在课程主项下以子列表展示，点击可查看对应星期、周次、节次和地点的明细。
- 课程大纲（桌面插件）：直接在扩展页面复用浏览器已有的 WebVPN 登录会话调用“培养 → 课程查询 → 课程大纲查询”的真实课程列表和课程大纲接口，不要求用户常驻打开原系统页面；支持课程号、课程名、开课单位、课程类别、课程性质和年级筛选。详情按原系统模块分组展示，基本信息按“课程概况 / 课程属性 / 学分与学时”紧凑组合，课程名称、课程号、学分、学时和课程属性不再重复铺成低密度长表；教材参考章节会区分先修课程、课外参考书及资料和课程使用的教材，不再把书目或先修课程笼统标为“教材参考信息”；基本信息后优先展示教材参考/先修，常见内部字段自动翻译为中文，课程成绩评定方法直接展开，记录标识、大纲版本等系统信息默认收起，并保留每个接口返回的全部原始字段、未知字段、空值和响应 JSON，可复制、下载完整数据或按需打开原系统查看。培养方案中点击任意课程详情后，会先按课程代码精确查询课程大纲并读取“课程使用教材”；代码没有命中时再按课程名称精确匹配，并把同名课程大纲列给用户手动选择；没有匹配记录时明确显示“课程大纲暂未收录此课程”。该入口仅在桌面插件提供，Android 端不显示。
- 当前学期单一数据源：设置页可从教务系统同步或从已读取的学期中手动指定当前学期；个人数据、个人课表、成绩、考试、全校课表初始值和新建本地安排全部读取同一持久化设置，不写死年份或学期代码。Chrome 使用本地设置保存，Android 同时镜像到 `SharedPreferences`。各查询页仍可临时切换历史学期，该选择只影响当前查询，不会反写全局当前学期；自动检测不可用时才按学期列表和日期动态兼容。
- 本地课表覆盖层：桌面插件可在个人课表中添加重复课程或一次性日程，支持编辑、复制、停用、删除、按学期隔离和一键管理；新建课程默认使用今天的星期和当前教学周，只添加本周一次，用户仍可修改为连续周、单双周或自定义周次。没有配置第一周日期时只自动填写星期，周次保持空白并明确提示，不会默认成整学期或偷偷回退到第 1 周。本地安排与教务课程分层合并，不会写入 `state.data.courses`、`scheduleDetail` 或教务缓存。冲突处理提供“保留现有 / 同时保留 / 仅保留新安排”，最后一种只在本机隐藏对应教务排课，并可恢复。
- 本地安排持久化：Chrome 使用 `chrome.storage.local`，Android 使用按学号 SHA-256 文件名隔离的 `local-schedule/` 目录和临时文件替换；清除教务缓存不会清除本地课程。一次性日程即使没有设置第一周日期，也会出现在总览、今天/明天和周表的其他日程区域；无法表达为 WakeUp CSV 的日期日程会明确提示跳过数量。
- 课表分周：个人课表和全校课表详情均支持“全部周次（叠加查看）”与指定单周视图，选择单周后只显示该周课程。
- 个人周表默认周次：在设置中配置“第一周周日”后，个人课表第一次切换到周表会自动定位当前学周；仍可选择“学期课表（全部周次叠加）”或其他周次。全校课表详情继续默认显示全部周次。
- 课表图片导出：个人课表和全校课表详情都可以导出整个学期或指定周的 PNG 图片；导出图片使用“节次 × 星期”网格，同格课程最多两列平铺，更多课程换到下一行，卡片按内容增高且不重叠，并按必修、选修、实验实践、通识、体育素养等类型使用不同的浅色背景增强区分，浏览器直接下载，Android 保存到“图片/执掌东大”。
- 课程详情：网格卡片和课程列表行均可点击，打开课程号、周次、星期、节次、时间、教师、地点、学分及原始字段详情。
- 课程属性：课表网格、日视图、课程列表和课程详情统一显示接口实际提供的考核方式（考试课/考察课）与课程性质（必修/选修）；某个页面完全没有对应字段时自动隐藏该标签、列和详情项，不留“待发布”空占位。
- 全校课表：动态读取“运行 → 课表查询 → 全校课表查询”允许的查询类型和课表模块学期，单独切换全校课表学期，不受顶部总览学期影响；会同步原系统权限，只展示当前账号实际开放的班级、教师和教室入口。
- 全校课表接口：按原系统实际的 `kbapp/modules/qxkbcx/*.do` 数据接口和 WebVPN 主机标记查询班级、教师和教室列表；每条班级、教师或教室结果都可直接点击“查看课表”，使用当前部署的动态类型码读取详情网格，并兼容旧的 `kbbpapp` 入口。详情网格有数据时不再请求会返回 403 的 `cxkblbms.do`。
- WebVPN 地址兼容：登录后优先使用原系统实际跳转到的 `/http/` 根地址，`/https/` 入口作为备用，避免接口返回登录页或 403 页面。
- 版本页防缓存：点击插件图标会打开带当前版本参数的新查询页，不会继续复用旧版已打开的页面。
- 延迟发布兼容：遇到“课表未发布/暂时无数据”会自动等待并重试；全校课表详情优先使用 `getScheduleDetail.do` 网格数据，只有网格为空时才兼容旧系统的 `cxkblbms.do` 课程列表，并按周次、星期、节次重新铺成周课表网格。
- 网格可读性：只按实际节次重叠分栏；同一时段但周次互斥的课程合并在同一卡片内，避免整列课程被挤成竖条。
- 同课程合并：只有课程身份、星期、节次和周次都一致的重复接口记录才合并；同名课程在不同星期、节次或周次的安排分别保留。
- 全校课表分页：自动读取原系统的全部服务器分页，并在插件内提供首页、上一页、下一页和末页导航。
- 时间地点解析：兼容周次、星期、节次、教师、校区、教学楼/教室、线上等字段；校区和教室分开归一化并持久化，课程列表及总览只展示教室/线上地点。
- 插件不保存账号或密码，只复用浏览器当前已登录的教务系统会话。
- 登录便捷性（安卓）：顶部提供内置登录、学校原网页账密和微信二维码三种入口，默认选中内置登录。内置页支持学号和密码，并在面板内提供手机验证码入口；旧版设备二次认证、新版图形验证码和手机短信流程都交给同一个可见的学校官方认证 WebView，默认勾选“信任此设备”。只在登录成功后才将账密以 Android Keystore AES-GCM 加密形式保存在本机，不保存验证码。手机验证码入口使用学校保留的官方模板和官方脚本完成图形验证码、短信发送、Cookie、账号选择与跳转，不复制私有接口；旧设备认证页中的可信设备选项也会同步为当前勾选状态。教务会话失效时直接使用加密凭据在不可见但持续运行的后台 WebView 重登，不再先尝试复用 E 码通业务会话；后台遇到人工验证会安全停止，不会自动发送或重放验证码。E 码通自身失效时也会独立触发同一后台登录，并在成功后只重载需要恢复的页面。认证若停在 CAS/WebVPN 中转页会限次重新探测目标入口，不再盲等到“未知页面”超时。如果需要人工验证或后台恢复失败，主界面底部会显示完整错误和“手动登录 / 其他方式”入口。
- 登录失败诊断（安卓）：后台或内置登录失败后，主界面提供“复制详细报错”按钮；报告包含应用/系统/WebView 版本、登录范围、触发方式、阶段、耗时、脱敏后的页面地址与标题、HTTP/WebView 错误和完整事件时间线，不包含密码、验证码、Cookie 值、Token 或完整查询参数。
- Android 图标：使用与应用界面一致的蓝色渐变、白色展开书页和金色书脊，同时支持 Android 8.0 及以上的自适应桌面图标与旧版本圆角图标。
- 状态提示：加载、后台登录、数据更新和导出反馈统一显示为底部导航上方的轻量提示，不再占用页面布局或遮挡顶部操作区；设置页使用独立标准滑块关闭一般 Toast，Android 通过 `SharedPreferences` 与页面状态双重保存，关闭后只保留缓存使用和数据刷新完成提示，需要用户处理的完整登录错误仍保留在手动登录入口旁。
- WebVPN 地址生成器：“更多工具”置于更多/设置页最上方，并提供纯本地的东北大学 WebVPN 地址转换工具；兼容原工具的 AES-128-CFB 域名编码规则，保留路径、查询参数和锚点，支持常用站点、复制及直接访问，不会上报使用统计或上传输入网址。
- 首页课程详情：首页的当前/下一项和“今天安排”课程均可直接打开详情弹窗；详情组件在首页即时渲染，切换页面时会清除旧选择，不会再延迟到课表页突然出现。
- 校园码弹窗隔离：Android 检测到课程详情、成绩详情、导出或工具等模态弹窗后会立即隐藏校园码并暂停顶部下拉识别；弹窗滚动不会冒泡触发校园码，关闭后也不会自动恢复，需在主页面重新顶部下拉。
- 弹窗路由一致性：设置页中的“管理自定义安排”和“添加安排”会在设置页立即打开，管理列表中的安排详情也不会延迟到课表页；切换页面、点击遮罩或使用 Android 返回键会统一清理全部弹窗状态，避免旧弹窗在后续页面突然出现。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 正常打开学校系统并登录。
5. 点击浏览器工具栏中的“东北大学教务焕新”图标，会打开独立查询页。

插件只向 `webvpn.neu.edu.cn` 发起请求，不会把账号或密码写入代码。电脑端登录继续使用学校原网页的“账号登录 / 二维码登录”双入口；若浏览器会话失效，查询页会提示先打开原系统登录，再点击“刷新数据”。

## 仓库结构

- `CODEMAP.md`：给人和后续 AI 的代码地图（模块边界、该改哪、硬约束）。
- `manifest.json`、`background.js`、`dashboard.*`：Chrome Manifest V3 插件源码。
- `android/`：Android 工程；构建时自动同步根目录的 `dashboard.html`、`dashboard.css` 和 `dashboard.js`。
- `tests/`：不依赖教务登录态的静态审计与移动端壳层 smoke tests。
- `api.md`、`design.md`：接口边界、隐私约束和界面设计说明。

## 发布与隐私

插件和 Android 安装包会随 GitHub Release 一起发布。Release 不包含任何账号、密码、Cookie、SSO ticket、Authorization、验证码或个人教务数据；这些内容只应存在于用户自己的登录会话和本机缓存中。

本项目与东北大学及其教务系统没有官方隶属关系。接口需要用户先在学校原系统完成登录，项目只复用当前登录态进行已授权查询；请遵守学校系统使用规则和相关法律法规。
